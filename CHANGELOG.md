# Changelog

## 0.1.0-beta.1 candidate — unreleased

- Floating Windows widget with on-demand Explorer selection, configurable shortcut and picker fallback.
- Safe PNG/JPEG/WebP conversion, sequential batches, copy path, move, rename and favorite folders.
- Optional local LibreOffice DOCX-to-PDF export with bounded preflight, property minimization, cancellation and no-overwrite finalization.
- Light/dark themes, keyboard actions, visible Settings controls and minimized-window recovery.
- Primary-action focus, Windows high-contrast palette precedence, paired selection colors, live-region status events and whole-DIP work-area sizing.
- Cached palettes and opt-in extended popup/Settings/hidden-idle measurements; CI checks extracted-package startup, memory and native compatibility.
- Offline F1 quick-start help and shortcut reopening of a hidden conversion with Cancel focused, preserving its selected files.
- Visible help focus in light/dark/contrast palettes, routed modal lifecycle checks and real Explorer/picker/native-cancellation acceptance evidence.
- Bounded cleanup of transient Windows sharing locks after document-engine shutdown, retaining and reporting persistent locks.
- Per-user classic Explorer verbs for images/DOCX and packaged installation, version switching, rollback and guarded uninstall tools.
- Validated installation previews with -WhatIf and an offline beta setup/upgrade/removal guide.
- Optional maintainer-supplied archive SHA-256 enforcement before preview or installation writes.
- Opt-in longer diagnostic idle intervals with sampled memory evidence and a real-world beta acceptance record.
- Windows CI for Release builds, automated tests, candidate package integrity and deployment lifecycle checks; separate real-renderer acceptance.

No public release has been approved. Windows 10 runtime, broad accessibility/DPI/hardware coverage, graphical/signed setup and long-duration stress testing remain beta gates. See docs/beta-readiness.md.
